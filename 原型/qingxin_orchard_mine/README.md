# 清新果园 · 我的页面原型

纯 HTML/CSS/JavaScript 静态原型，解压后直接打开 `index.html` 即可运行，无需安装依赖或启动服务。

## 目录
- `index.html`：页面入口
- `css/style.css`：样式与响应式布局
- `js/app.js`：交互逻辑
- `assets/images/`：本地图片素材

## 原型交互
- 个人资料入口：弹出个人资料提示
- 我的收藏：弹出收藏页面说明
- 我的留言：弹出留言记录说明
- 申请成为商家：弹出商家入驻说明
- 底部导航：可切换选中状态并显示演示提示

此页面为展示型内容平台的个人中心，不含商城、购物车、支付等功能。
